# COLLISEUM UNITY

## Tecnologías utilizadas

* Unity
* C#
* Blender
* Git
* GitHub

## Sistemas implementados

* Gestión de estados del juego (State Manager)
* Gestión de rondas (Round Manager)
* Sistema de generación de enemigos
* Sistema básico de combate
* Interfaz de usuario
* Gestión de escenas

## Objetivos del proyecto

* Desarrollar un videojuego funcional de principio a fin.
* Aprender a estructurar proyectos de Unity.
* Practicar el uso de Git y GitHub.
* Integrar modelos creados en Blender dentro de Unity.
* Aplicar conceptos de programación modular.
